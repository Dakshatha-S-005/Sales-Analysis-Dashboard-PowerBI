**Sales Analysis Dashboard using Power BI**

## Project Overview
Developed an interactive Sales Analysis Dashboard using Microsoft Power BI to analyze sales performance, profitability, product categories, regional sales and customer segmentation.

## Tools & Technologies
- Microsoft Power BI
- SQL
- DAX
- Data Visualization
- Data Analysis

## Dashboard Features
- Total Sales, Total Orders, Total Profit and Average Order Value KPIs.
- Top 10 Products by Profit.
- Monthly Sales Trend Analysis.
- Sales by Product Category.
- Sales by Region.
- Customer Segmentation Analysis.
- Interactive Year, Category and Region slicers.

## Key Objectives
- Analyze overall business sales performance.
- Identify profitable products and categories.
- Compare sales across different regions.
- Understand customer purchasing patterns.
- Support data-driven business decisions.
